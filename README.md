# GenAI From Scratch 🧠

A hands-on learning portfolio built in 3 weeks — covering transformer 
fundamentals, embeddings, vector databases, and a full RAG pipeline 
with an agent layer, all built from scratch.

## 📁 What's Inside

| Notebook | What it covers |
|----------|---------------|
| `day2_self_attention.ipynb` | Self-attention head from scratch — Q, K, V projections, causal masking, scaled dot-product, training loop |
| `day3_embeddings_vectordb.ipynb` | Text embeddings, cosine similarity, ChromaDB setup and similarity search |
| `day4_naive_rag.ipynb` | Complete RAG pipeline — chunking, embedding, retrieval, LLM generation with Groq |
